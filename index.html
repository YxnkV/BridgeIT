Connect your database

This uses Firebase (free, hosted by Google) so every observer's device can save to the same place. Takes about 5 minutes, one time only.

  1. Go to console.firebase.google.com → "Add project" → give it any name → finish creation (Google Analytics not needed).
  2. In the left menu: "Build" → "Firestore Database" → "Create database" → choose "Start in test mode" → pick any location → Enable.
  3. Click the gear icon → "Project settings" → scroll to "Your apps" → click the </> (web) icon → register the app (any nickname) → skip hosting.
  4. Copy the whole firebaseConfig object shown (starts with { apiKey: ...) and paste it below.

Note: "test mode" Firestore rules are open to anyone with this config for 30 days — fine for a short pilot. For anything longer-running, tighten the rules in the Firebase console under Firestore → Rules.
